LocaleProof — Unity Editor tool

Available on the Unity Asset Store

Moves translation text you exported from I2 Localization into Unity's official Localization package, then compares the imported String Tables against your original export — every imported key, every cell. Runs entirely inside the Unity Editor.

View LocaleProof on the Unity Asset Store →

Tested on Unity 6000.3.22f1 (Localization 1.5.4 and 1.5.9) and Unity 6000.6.0f1 (Localization 1.5.13).

CSS Class Scope — VS Code extension

In development

CSS class autocomplete that stays inside the package you are editing. In a monorepo, completion, go to definition and find references stop offering classes from unrelated packages, and common nested SCSS selectors resolve to the class names they compile to.

Built and benchmarked against the free alternatives we tested; not yet published to the Visual Studio Marketplace. The measurements behind the comparisons are public: github.com/shiroipapa/benchmarks.
