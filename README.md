# shiroipapa.github.io — Shiroipapa Apps

The public website for **Shiroipapa Apps**: small Editor tools for Unity developers and
extensions for code editors.

Live site: <https://shiroipapa.github.io/>

## What is in here

Static HTML and CSS, with small inline scripts for the animations on the home and LocaleProof
pages. No build step, no framework, no package manager, and no external scripts.

```
index.html                 Home
products/index.html        Product list with status
products/localeproof/      LocaleProof product page
about/index.html           What we work on and how it is verified
support/index.html         Support and contact
privacy/index.html         Privacy
404.html                   Not found
assets/css/site.css        The only stylesheet
assets/img/brand/          Logo and icons
assets/img/localeproof/    LocaleProof images
assets/img/css-class-scope/ CSS Class Scope icon
```

## Principles for this repository

- **No tracking.** No analytics, no tag manager, no advertising scripts, no cookies.
- **Nothing added from third parties.** No web fonts, CDNs, or embedded widgets; every asset the pages reference is in this repo. (GitHub Pages, as the host, is outside our control.)
- **Public material only.** Product source code, internal notes, review material and anything
  private live elsewhere and never enter this repository.

## Editing

Open the HTML files directly. The pages share one stylesheet and a copied header/footer; when the
header or footer changes, update every page.
