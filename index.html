How these tools are built

The same three rules apply to everything here

One job, stated plainly

A tool says what it covers and what it does not. Anything out of scope is listed up front, not discovered half-way through.

Measured, not claimed

Compatibility and behaviour are established by tests that run on the actual software — real Unity Editors — and only the combinations we measured are listed as supported.

Safe by default

For tools that write files: nothing is written until you ask for it, files the tool did not create are overwritten only when you explicitly allow it, and what it generates can be rolled back.

Move with confidence. Verify before you trust.
