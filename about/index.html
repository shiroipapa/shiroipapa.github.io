About Shiroipapa Apps

A small independent studio building Editor tooling for developers.

Shiroipapa Apps makes tools for two kinds of working day: inside the Unity Editor, and inside a code editor. The common thread is unglamorous work that is easy to get wrong by hand — moving data from one system to another, checking that nothing was lost on the way, and keeping a large project navigable.

What we work on

Unity Editor tooling

Editor windows and pipelines that run inside Unity, using the official packages and public APIs. Nothing to run from a command line.

Migration and validation

Moving localization data between systems, and then verifying the result cell by cell instead of spot-checking it.

Developer workflow

Editor extensions that cut repetitive lookups in large codebases — scoped completion, navigation, and reports on what is unused.

How the work is verified

  • Behaviour is covered by automated tests that run on the real software — for Unity products, on real Unity Editors, with negative tests that must fail when the code is broken.
  • Only combinations that were actually measured are listed as supported. Versions that were not tested are not claimed.
  • Comparisons against other tools are published with the details behind them: github.com/shiroipapa/benchmarks.
  • Where a competing tool does something better, that goes on the benchmark page too.
