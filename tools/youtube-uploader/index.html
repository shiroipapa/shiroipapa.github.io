Channel Upload Tool

Privacy policy and terms · Last updated 2026-10-22

What this is

A private tool that runs only on the channel owner's own computer. The owner uses it to upload videos to their own YouTube channel and to set titles, descriptions, captions, thumbnails and playlists, and to read that channel's YouTube Analytics. It is not offered, sold or distributed to anyone else.

Google data the tool uses

  • youtube.upload — to upload the owner's videos.
  • youtube.force-ssl — to edit the owner's own video details, captions, thumbnails and playlists.
  • yt-analytics.readonly — to read view and watch-time figures for the owner's own channel.

The tool only acts on the channel the owner authorizes, and only when the owner runs it.

Storage and sharing

  • The sign-in token is kept in the owner's computer keychain. Nothing is stored on a server.
  • Data received from Google is used only on the owner's computer for the purposes above. It is not sold, shared with third parties, used for advertising, or used to train AI models.
  • The tool sends requests only to Google's own APIs.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party connections. Revoking it stops the tool from working; the tool keeps no copy of channel data elsewhere.

Terms

The tool is for the owner's personal use only and is provided as is. Use of YouTube through it is subject to the YouTube Terms of Service.
